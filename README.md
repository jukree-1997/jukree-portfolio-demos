# Jukree Donkittikun — Interactive Project Demos

Three browser-based portfolio showcases built to explain selected software projects. They use new HTML, CSS, JavaScript and SVG, and run as static pages. The original company application source is not included.

## Demos

- [Smart Relabeling](smart-relabeling/index.html) — dataset review, editable boxes, illustrative auto-labeling and a model-building preview. The team reported labeling 8,000 images in under two days using the original desktop application.
- [Fiber Angle Inspection](fiber-angle-inspection/index.html) — a fictional QC workflow and an approved representative saved camera result. The result is an uncalibrated evaluation output and does not establish accuracy or production acceptance.
- [Video Analytics Toolset](video-analytics-toolset/index.html) — camera setup, processing and reporting handoffs, with a fictional dashboard mockup.

The demos are self-contained and work offline. Sample records and analytics are identified as fictional; saved fiber images are clearly identified as evaluation outputs. Each project README describes its behavior and limitations.

GitHub Pages can serve the files as interactive demos using the workflow in `.github/workflows/pages.yml`.
